# Beyond the City

**Beyond the City**는 제한된 지역에서 시작하여 게임을 진행하면서 새로운 도시와 활동 영역을 하나씩 해금해 나가는 Minecraft NeoForge 모드입니다.

플레이어는 처음에는 원점을 중심으로 한 제한된 도시 영역에서 시작하며, 도시의 경계를 넘어갈 수 없습니다. 게임을 진행하고 특정 조건을 달성하면 서로 떨어져 있는 새로운 도시들이 차례로 해금되고, 이에 따라 플레이어가 탐험할 수 있는 세계의 범위가 점차 넓어집니다.

## 개발 환경

* **Minecraft:** 26.1.2
* **Mod Loader:** NeoForge
* **Gradle Plugin:** ModDevGradle
* **Java:** 25
* **IDE:** IntelliJ IDEA

## 모드 정보

* **Mod Name:** Beyond the City
* **Mod ID:** `njw_beyond_the_city`
* **Package:** `net.njw.beyondthecity`

## 주요 컨셉

* 제한된 도시 영역에서 게임 시작
* 도시 경계를 통한 플레이어 활동 영역 제한
* 게임 진행에 따른 새로운 도시 해금
* 서로 떨어진 여러 도시를 중심으로 활동 영역 확장
* 도시별 독립적인 해금 상태 관리

예를 들어 최초 도시는 월드 원점 `(0, 0)`을 중심으로 구성되며, 이후 게임 진행에 따라 멀리 떨어진 새로운 도시가 해금되는 방식입니다.

## 개발 상태

현재 초기 개발 단계입니다.

모드의 기본 구조와 도시 영역 및 해금 시스템부터 순차적으로 구현할 예정입니다.

## 개발 순서

1. **기본 모드 실행 확인**

    * NeoForge 개발 환경에서 클라이언트가 정상 실행되는지 확인
    * 모드가 정상적으로 로드되는지 확인
    * 로그를 통해 `njw_beyond_the_city` 모드가 정상 등록되었는지 확인

2. **도시 영역 데이터 구조 구현**

    * 각 도시의 중심 좌표를 저장
    * 도시의 가로/세로 크기를 청크 단위로 정의
    * 도시별 고유 ID 및 이름 관리
    * 도시의 해금 여부를 저장할 수 있는 구조 설계

   초기 테스트 예시:

    * City 0: 중심 `(0, 0)`, 크기 `64 × 64 chunks`
    * City 1: 중심 `(10000, 10000)`, 크기 `64 × 64 chunks`

3. **도시 영역 판정 기능 구현**

    * 플레이어의 현재 위치가 해금된 도시 영역 내부인지 확인
    * 블록 좌표와 청크 좌표 변환 처리
    * 여러 도시가 존재할 경우 어느 도시 영역에 속하는지 판정

4. **플레이어 이동 제한 구현**

    * 최초에는 시작 도시만 해금
    * 해금되지 않은 영역으로 플레이어가 이동하지 못하도록 제한
    * 경계를 넘으려 할 경우 기존 위치로 되돌리거나 이동을 차단
    * 서버 측에서 판정하여 멀티플레이 환경에서도 동일하게 동작하도록 구현

5. **도시 해금 상태 저장**

    * 월드별로 해금된 도시 목록을 저장
    * 게임을 종료하고 다시 접속해도 해금 상태가 유지되도록 구현
    * 싱글플레이와 서버 환경에서 동일한 저장 구조 사용

6. **도시 해금 기능 구현**

    * 테스트용 명령어를 통해 특정 도시를 해금할 수 있도록 구현
    * 예시:
      `/btc unlock city_1`
    * 해금된 도시의 영역에는 정상적으로 진입할 수 있도록 처리

7. **도시 해금 조건 구현**

    * 플레이 시간
    * 특정 아이템 획득
    * 특정 보스 처치
    * 퀘스트 완료
    * 이전 도시에서의 특정 목표 달성

   초기 개발 단계에서는 단순한 플레이 시간 또는 명령어 기반 해금을 우선 구현하고, 이후 실제 게임 진행 조건으로 확장합니다.

8. **플레이어 피드백 추가**

    * 잠긴 지역에 접근할 경우 메시지 표시
    * 새로운 도시가 해금되었을 때 알림 표시
    * 현재 해금된 도시 목록 확인 기능 추가

9. **도시 관리 기능 확장**

    * 도시별 이름 및 설명
    * 도시별 크기 설정
    * 서로 다른 도시 좌표 설정
    * 도시별 해금 조건 설정
    * 설정 파일 또는 데이터 파일을 통한 도시 추가

10. **추가 시스템 확장**

    * 도시별 바이옴 및 환경 차별화
    * 도시별 자원 및 몬스터 구성
    * 도시 간 이동 시스템
    * 지도 또는 UI를 통한 도시 상태 표시
    * 서버 관리자용 도시 관리 명령어
